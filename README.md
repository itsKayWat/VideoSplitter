## ✨ Features
- **100% Client-Side Processing**: All video splitting occurs locally inside your web browser. Zero server uploads.
- **Platform Matrix**: Built-in specs for Instagram Stories/Reels, TikTok, WhatsApp Status (30s / 16MB), YouTube Shorts, Twitter/X, Discord, Telegram, and Snapchat.
- **Custom Split Modes**: Split by custom seconds per clip or split into equal part counts.
- **Time Range Selection**: Trim specific sections before splitting.
- **Batch Actions & Direct Share**: Download all clips as a single ZIP archive, trigger direct batch file downloads, or share clips directly using native Web Share API.
- **Real-Time Progress & Previews**: Live segment encoding progress indicators with interactive video clip thumbnails.

---

## 🚀 How to Use
1. Visit **[https://videosplitter.kaywat.codes/](https://videosplitter.kaywat.codes/)**.
2. Upload your video file or paste a video URL.
3. Select your target platform (Instagram, TikTok, WhatsApp, etc.) or set a custom split duration.
4. Click **Split Video**.
5. Download your processed clips individually or as a ZIP archive!
